To-Do List Web Application
A simple, interactive and responsive To-Do List Web Application that helps users organise their daily activities by allowing them to add, edit, complete and delete 
tasks.

Tasks are automatically saved in the browser using Local Storage, so they remain available even after refreshing 
the page.

Features
Add Tasks: Create new tasks using the input field and Add Task button.
View Pending Tasks: Newly added tasks automatically appear in the pending tasks section.
Complete Tasks: Mark tasks as completed or move them back to pending.
Edit Tasks: Modify existing task descriptions.
Delete Tasks: Permanently remove unwanted tasks.
Task Counters: Display the total number of pending and completed tasks.
Timestamps: Show when each task was created.
Local Storage: Automatically save tasks in the browser.
Empty State Messages: Display friendly messages when there are no tasks.
Responsive Design: Works on desktop and mobile devices.
 
Tech Stack
Technology	Purpose
HTML5	Structures the application
CSS3	Handles styling and responsive design
JavaScript	Implements application functionality
Local Storage	Saves tasks in the browser

Project Overview
The To-Do List App is designed to help users manage their daily tasks efficiently. It provides separate sections for pending and completed tasks, making it easier to track progress and stay organised.
