TEMPERATURE CONVERTER 
This project creates a responsive temperature converter that converts values between Celsius (°C), 
Fahrenheit (°F), and Kelvin 

Features:
Numeric temperature input with real-time validation.
Dropdown menu for selecting the input temperature unit.
Convert button to trigger calculations.
Simultaneous conversion into all three temperature units.
Absolute zero validation.
Clear error messages for invalid inputs.
Clean, centred and responsive design.

Tech Stack:
HTML5, CSS3 and Javascript
