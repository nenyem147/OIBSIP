JavaScript Calculator Project
Below is a complete, functional calculator built with HTML5, CSS3, and Vanilla JavaScript.

It includes all your requested features, including operator chaining, decimal numbers, backspace, 
division-by-zero protection, and CSS Grid.

The calculator follows standard mathematical precedence, so 5 + 3 × 2 produces 11, not 16.
 It uses custom calculation logic without eval().

 Tech Stack:
 HTML5, CSS3 and Javascript

HTML – index.html
This creates the calculator display and buttons.

CSS – style.css
This styles the calculator and uses CSS Grid to arrange the buttons.

JavaScript – script.js
This handles all calculator operations, button clicks, calculations, and error handling.

It uses variables, functions, conditional statements, switch, and parseFloat() instead of eval().
