Personal Digital Portfolio – Okoye Chinenye Ifeanyi
Project Description

The Personal Digital Portfolio is a responsive website developed to showcase my professional background, educational qualifications, technical skills, work experience, and personal projects.

The website serves as a digital representation of my professional journey as an aspiring software developer and junior frontend developer. It provides visitors, recruiters, and potential collaborators with an overview of my background, capabilities, and career aspirations.

The project was developed as part of my frontend web development learning journey through the OIBSIP Web Development Internship.

Features
Responsive Navigation: Provides easy navigation between different sections of the portfolio.
Hero Section: Introduces me as an aspiring software developer and provides quick links to my projects and contact information.
About Me: Highlights my personal background, professional journey, interests, and career goals.
Skills Section: Showcases my technical skills, software development knowledge, communication abilities, and professional strengths.
Projects Showcase: Displays selected projects and frontend development practice.
Work Experience: Highlights my previous professional roles, responsibilities, and transferable skills.
Education and Training: Presents my academic qualifications, professional certifications, and ongoing software development training.
Contact Section: Provides visitors with my email address, phone number, and location for professional enquiries.
Call-to-Action Links: Makes it easy for recruiters and potential collaborators to get in touch.
Footer: Displays copyright information and a brief personal tagline.

Tech Stack
HTML5: Used to structure the website and organize its content into different sections.
CSS3: Used for styling, page layout, colours, typography, and responsive design.
Google Fonts (Inter): Used to improve the website's typography and visual presentation.
